## Topics Covered

### Stacks

A stack is a linear data structure that follows the **LIFO** principle. The assignment covers the following stack operations:

* `push()`
* `pop()`
* `peek()` / `top()`
* `isEmpty()`
* `isFull()`
* `displayAll()`

The assignment also examines stack overflow and underflow and discusses array-based stack implementations.

### Queues

A queue is a linear data structure that follows the **FIFO** principle. The following operations are discussed:

* `enqueue()`
* `dequeue()`
* `isEmpty()`
* `isFull()`
* `displayAll()`

The assignment also explains queue overflow and underflow and the limitations that can occur when implementing a queue using a linear array.

### Circular Queues

Circular queues address the unused-space problem that can occur in a basic linear array queue.

A circular queue treats the array as a continuous structure. When the rear reaches the last position, it can wrap around to the beginning of the array when space is available.

This allows previously unused positions to be reused and makes the available array space more efficient.

### Binary Trees

The assignment introduces the structure and terminology associated with binary trees, including:

* Nodes
* Root
* Parent
* Child
* Left child
* Right child
* Leaf
* Subtree

A binary tree allows each node to have a maximum of two children.

### Binary Search Trees

A **Binary Search Tree (BST)** is a specialized type of binary tree that follows an ordering rule:

* Values smaller than a node are placed in the left subtree.
* Values greater than a node are placed in the right subtree.

The assignment explains how this organization can make searching for values more efficient.

It also covers:

* BST insertion
* BST searching
* Duplicate values
* Predecessors
* Successors
* Basic BST node structure
