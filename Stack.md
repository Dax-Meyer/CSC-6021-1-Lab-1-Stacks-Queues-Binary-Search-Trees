What Is a Stack?

A stack is a linear data structure that stores and organizes elements in a specific order. A stack follows the LIFO principle, which stands for Last In, First Out. This means that the last item added to the stack is the first item that will be removed. You can think of a stack in everyday life as a pile of books on a desk. Imagine that you place a math book on the desk, then put a science book on top of it, and finally place an English book on top of the science book. If you want to remove a book without moving the others, you would have to take the English book off first because it is on the top. The English book was the last book you added, so it is the first book you remove. This is exactly how a stack works. It follows Last In, First Out (LIFO). It is important to remember that a stack uses LIFO, not FIFO. FIFO, which stands for First In, First Out, is a different method used by a queue. A good everyday example of FIFO is a line at a store, where the person who gets in line first is normally the first person served.
The main operations performed on a stack are push(), pop(), peek() or top(), isEmpty(), isFull(), and displayAll(). These operations can also be understood using the pile of books example. The push() operation means adding a new item to the top of the stack. For example, if you have a pile of books and place another book on top, you have performed a push operation. The pop() operation means removing the item from the top of the stack. If the English book is currently on top of the pile, removing it would be a pop operation. The peek() or top() operation allows you to look at or identify the item on top without removing it. For example, you could look at the title of the English book to see which book is on top, but you would leave the book where it is. The isEmpty() operation checks whether there are any items in the stack. If there are no books in the pile, the stack is empty. The isFull() operation checks whether the stack has reached its maximum capacity. For example, if you have a small shelf that can safely hold only five books, once five books are placed on it, the stack can be considered full. Finally, displayAll() means looking at or showing all of the items currently in the stack, such as listing all of the books in the pile.
Stack overflow can also be understood using the pile of books example. Imagine that you have a small shelf that can safely hold only five books. If five books are already on the shelf and you try to place a sixth book on it, there is no available space. In a computer program, this situation is called stack overflow. In an array-based stack, the array has a specific maximum capacity, so trying to use push() when the stack is already full can cause a stack overflow.
Stack underflow is the opposite situation. Imagine that you have a pile of books, but there are no books left in the pile. If someone asks you to remove a book from the pile, you cannot do it because there is nothing there. In a stack, this is called stack underflow. Stack underflow happens when a program attempts to use pop() on an empty stack. This is why a program can use isEmpty() before performing pop(), allowing it to check whether there is actually an item available to remove.
An array-based stack is a stack that uses an array to store its elements. An array can be thought of as a set of spaces or compartments that can hold a specific number of items. For example, imagine a bookshelf that has five spaces for books. Each space represents a position in the array, and the books represent the elements stored in the stack. A variable called top is commonly used to keep track of which position contains the top item. If the English book is currently the last book placed on the shelf, the top would keep track of its position. When another book is added, the top position changes to the new book.
Array-based stacks have several advantages. One advantage is that they are relatively simple to create and understand. Using the bookshelf example, you know exactly how many spaces are available and where the books can be placed. Another advantage is that common stack operations such as push(), pop(), and peek() can be performed very quickly, generally in O(1) time. Array-based stacks can also use memory efficiently because the elements are stored in an organized sequence. They also do not require additional pointer information for every element, which can make them simpler than some other implementations.
However, array-based stacks also have limitations. The biggest limitation is that a traditional array has a fixed size. Going back to the bookshelf example, imagine that your bookshelf has only five spaces. Once all five spaces are filled, you cannot simply add another book unless you make the shelf bigger or get another shelf. In the same way, an array-based stack can only hold as many elements as its capacity allows. If the stack is full and you try to add another element, a stack overflow can occur. Another limitation is that space can be wasted. For example, if your bookshelf has 100 spaces but you only have five books, 95 spaces are currently unused. Similarly, an array-based stack may have allocated space that is not being used. If the stack uses a dynamic array that can grow, the program may need to create a larger array and copy the existing elements into it when more space is required.
Overall, a stack can be understood as a pile where you can only easily add or remove something from the top. The pile of books example demonstrates the LIFO principle because the last book placed on the pile is the first book that can be removed. The push() operation adds something to the top, pop() removes something from the top, and peek() or top() looks at the top item without removing it. isEmpty() checks whether the stack contains anything, isFull() checks whether the stack has reached its capacity, and displayAll() shows all of the elements in the stack. Stack overflow happens when you try to add something to a full stack, while stack underflow happens when you try to remove something from an empty stack. An array-based stack is simple and fast, but its main limitation is that it has a limited amount of space unless the array is resized.
